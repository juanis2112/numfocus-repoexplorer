# NumFocus Sponsored Projects Explorer

An interactive dashboard built with [Shiny for Python](https://shiny.posit.co/py/) to browse, filter, and analyze the **63 NumFOCUS sponsored projects** and their GitHub repository health metrics.

## Overview

This app pulls live GitHub data for every NumFOCUS sponsored project and presents it across six interactive tabs:

| Tab | What you'll find |
|-----|-----------------|
| **About** | Project background and data sources |
| **Overview** | Stars, forks, contributors, languages at a glance |
| **Projects** | Searchable, sortable table of all 63 projects |
| **Impact** | Download counts, community adoption metrics |
| **Sustainability** | Bus factor, contributor distribution, health scores |
| **Security** | OpenSSF Scorecard results for each project |

Sidebar filters let you slice by **programming language**, **feature area**, **industry**, **license**, **stars**, **forks**, and **sponsorship year**.

## Quickstart (local)

### 1. Create a conda environment

```bash
conda create -n numfocus-explorer python=3.12
conda activate numfocus-explorer
pip install -r requirements.txt
```

### 2. Add your GitHub token

Create a `.env` file in this directory:

```
GITHUB_TOKEN=ghp_your_token_here
```

A classic personal access token with **public_repo** read scope is sufficient. Without a token the GitHub API is rate-limited to 60 requests/hour; with one it's 5,000.

### 3. Collect data

```bash
bash run_collection.sh
```

This takes roughly 5–10 minutes for all 63 projects and writes two parquet files to `Data/parquet/`.

### 4. Run the app

```bash
python -m shiny run app.py
```

Then open [http://localhost:8000](http://localhost:8000) in your browser.

---

## Refreshing the data

Re-run `bash run_collection.sh` any time you want updated GitHub metrics and Scorecard results. The parquet files will be overwritten in place.

## Deploying to Posit Connect Cloud

1. **Collect data first** (see step 3 above) — the parquet files must exist before deploying.
2. Install the rsconnect CLI if you haven't already:
   ```bash
   pip install rsconnect-python
   ```
3. Authenticate with your Posit Connect account:
   ```bash
   rsconnect add --server https://connect.posit.cloud --name posit-cloud --token <YOUR_API_KEY>
   ```
4. Deploy from inside this directory:
   ```bash
   rsconnect deploy shiny . --name posit-cloud --title "NumFocus Explorer"
   ```

The `Data/parquet/` files are included in the deployment bundle so the app works immediately without re-running the collector on the server.

> **Note:** The `.env` file is excluded from deployment (it's in `.gitignore`). Do not store your GitHub token in any committed file.

## Data Sources

- **GitHub REST API v3** — repository metadata, contributor counts, language breakdown, release downloads, community health files
- **OpenSSF Scorecard API** (`api.securityscorecards.dev`) — security posture scores across 17 checks for each project
